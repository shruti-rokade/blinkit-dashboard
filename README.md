🛒 Blinkit Sales Analysis Dashboard

An interactive Power BI dashboard built to analyse Blinkit's sales performance across product categories, outlet characteristics, and customer ratings.

📊 Project Overview
This project uses the Blinkit sales dataset to explore key business metrics and identify trends in sales, product performance, outlet size, outlet location, item visibility, and customer ratings.
The dashboard allows users to interact with the data using filters and explore different aspects of outlet and product performance.

🎯 Objectives
Analyse overall sales and product performance.
Identify top-performing product categories.
Compare sales across different outlet sizes and location types.
Analyse outlet establishment trends over time.
Understand the relationship between item visibility and sales.

🛠️ Tools & Technologies
Power BI – Dashboard development and data visualisation
Power Query – Data cleaning and transformation
DAX – Measures and calculated metrics
Excel/CSV – Dataset

🔍 Key Insights
Fruits & Vegetables and Snack Foods are among the highest-selling categories.
Tier 3 outlets contribute the highest sales among the three outlet location tiers.
Sales show fluctuations across outlet establishment years, with a notable peak around 2018.
The dashboard enables comparison of sales performance across outlet types and sizes.
